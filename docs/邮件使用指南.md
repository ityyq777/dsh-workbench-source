# 邮件使用指南（0.5.6）

## 连接邮箱

在凭据保险箱中创建并解锁邮箱授权码凭据，然后在「邮件 → 账户」选择服务商、填写邮箱并选择凭据。先做连接测试，再保存。账户只保存凭据 ID。IMAP 使用隐式 TLS，或先用 STARTTLS 升级，加密成功才发送登录信息；服务器不支持升级时不会回退到明文登录。请根据邮件服务商提供的端口和加密方式配置。

移除账户会从列表、搜索、统计和数据页隐藏其邮件，不清除本地缓存，也不修改远端邮箱。

## 自动收新邮件

邮件插件默认在后台自动收信，不必一直开着邮件页。设置项在「邮件 → 设置 → 自动同步」：

- **自动收取新邮件**：默认开启。关掉后只有你打开邮件视图、切文件夹时才抓信。
- **同步方式**：默认「定时循环」，每隔一段时间连一次服务器，兼容所有邮箱；「IMAP 推送」让服务器主动通知，收信更快，少数服务商不支持或会掐断长连接，此时插件按 5 秒到 5 分钟逐次退避重连，同时仍按下面的间隔兜底检查。
- **定时间隔**：60–1800 秒，默认 300 秒。太短可能被邮箱服务商限流；「IMAP 推送」模式下它是兜底检查周期。
- **新邮件通知到消息中心**：装了消息插件时，每批新邮件会在消息中心留一条提醒（同一批只提醒一次）。

**先解锁保险箱，后台才会收信。** 自动同步每一轮都先检查保险箱状态，锁着就整轮跳过——不连服务器、不报错、也不缓存你的密码。设置页顶部那行状态会写「正在运行：定时循环，300s · 上次 14:30:00」，保险箱锁着时会显示「因保险箱锁定跳过 N 次」。解锁后下一轮自动恢复，不需要重启。

新邮件只抓信头（发件人、主题、时间、附件名），打开才取正文，与手动同步一致。自动同步只处理收件箱；其他文件夹仍按需同步。

## 查找旧邮件

选定账户并同步文件夹，然后选择收件箱或其他文件夹。同步先取信头，不下载全部正文和附件。本地翻页只能看到已经同步的邮件；要查未同步的来信，先选择账户和远端文件夹，再输入关键词并点击「在服务器搜索」。该操作只缓存至多 50 封匹配信头，不下载正文，也不清理其他本地邮件。认证失败或超时会单独报错。关键词只匹配本地主题或发件地址，不匹配正文、附件内容或尚未同步的服务器邮件。

空文件夹与同步失败不是同一种结果。认证失败时检查账户和授权码；文件夹被拒绝时检查文件夹是否存在、账户是否有权限，然后重试。

在「全部账户」中，默认是「统一收件箱」：只汇总启用账户的收件箱，并标出来源。可切换到「全部邮件」查看其他文件夹，两种范围均支持未读筛选和本地翻页。

列表按日期分组。宽屏下发件人、主题和时间分列显示，窄屏下分行显示。今天显示时分，昨天带时分，本年较早邮件显示月日，跨年显示年份。宽列表同时显示本地已知附件名，窄列表只显示附件图标。附件标记来自本地已知的附件信息，未看到标记的邮件仍可能含有附件。

## 阅读、移动和下载

从侧栏可直达当前账户已有的常用文件夹。点击「展开阅读」可让正文占满侧栏以外的主区域。发件地址、收件账户和收信时间可直接核对，收件人和抄送名单可展开。「上一封」和「下一封」按打开邮件时的顺序，在当前筛选页内切换。要读另一页，先返回列表再翻页。返回时会保留筛选、页码和打开第一封邮件前的滚动位置。

打开一封信时，插件读取正文分段并列出附件名称，不会为了显示一小段文字下载整封大邮件。只有附件的信也可以直接选附件保存。保存时只下载选中的附件；单附件的传输大小上限是 32 MiB（按邮件编码后的大小计算）。超限可在原邮箱下载；文件夹或邮件结构变化时先重新同步并打开邮件。

对远端邮件标记已读或未读、移动文件夹或移入废纸篓，会改变原邮箱中的状态。删除不是永久删除，也不会清空废纸篓。操作报错时请查看原因，刷新文件夹后核对原邮箱，不要把错误提示当作操作成功。

批量移入废纸篓只处理本页勾选的邮件。「本页全部标为已读」只处理打开确认时本页可同步的未读邮件。核对确认框中的账户和封数后再执行。遇到部分失败，可核对失败项并单独重试。

## 回信与草稿

在原信上选择回复、全部回复或转发。回复与转发使用原信账户；发出前请核对收件人与抄送，特别是「全部回复」。正文是纯文本。写信可以添加和移除本机文件；转发原附件默认不勾选，只随信发送明确选中的附件。两类附件合计最多 10 个、8 MiB，文件无法读取时整封邮件不会提交。附件选择只保留在当前编辑会话，不写入草稿。保留的未发草稿可在本机继续编辑，不会出现在其他设备或服务商的草稿箱。

「写信 → 投递记录」区分 SMTP 拒收、服务器已接收但本地未留档，以及未收到最终回执。「补记本地已发送」不会再次发信，也不保存附件字节。结果未知时请先核对邮箱，不要重发。

附件、服务器搜索、投递记录和草稿只在界面使用。其他发送、移动和同步动作默认不对 agent 开放。工作台不提供 OAuth2 登录、服务器全文搜索或永久删除。
