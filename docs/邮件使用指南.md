# 邮件使用指南（0.3.0）

## 连接邮箱

在凭据保险箱中创建并解锁邮箱授权码凭据，然后在「邮件 → 账户」选择服务商、填写邮箱并选择凭据。先做连接测试，再保存。账户只保存凭据 ID。IMAP 使用隐式 TLS，或先用 STARTTLS 升级，加密成功才发送登录信息；服务器不支持升级时不会回退到明文登录。请根据邮件服务商提供的端口和加密方式配置。

## 查找旧邮件

选定账户并同步文件夹，然后选择收件箱或其他文件夹。同步先取信头，不下载全部正文和附件。本地翻页只能看到已经同步的邮件；要查更早的来信，先在该文件夹继续拉取历史，再搜索。关键词只匹配本地主题或发件地址，不匹配正文、附件内容或尚未同步的服务器邮件。

空文件夹与同步失败不是同一种结果。认证失败时检查账户和授权码；文件夹被拒绝时检查文件夹是否存在、账户是否有权限，然后重试。

## 阅读、移动和下载

打开一封信时，插件读取正文分段并列出附件名称，不会为了显示一小段文字下载整封大邮件。只有附件的信也可以直接选附件保存。保存时只下载选中的附件；单附件的传输大小上限是 32 MiB（按邮件编码后的大小计算）。超限可在原邮箱下载；文件夹或邮件结构变化时先重新同步并打开邮件。

对远端邮件标记已读或未读、移动文件夹或移入废纸篓，会改变原邮箱中的状态。删除不是永久删除，也不会清空废纸篓。操作报错时请查看原因，刷新文件夹后核对原邮箱，不要把错误提示当作操作成功。

## 回信与草稿

在原信上选择回复、全部回复或转发。回复与转发使用原信账户；发出前请核对收件人与抄送，特别是「全部回复」。转发的是纯文本内容，不会自动发送原附件。保留的未发草稿可在本机继续编辑，不会出现在其他设备或服务商的草稿箱。

附件保存与草稿操作只在界面使用，不能通过 agent 打开权限。其他发送、移动和同步动作默认不对 agent 开放。工作台不提供 OAuth2 登录、附件上传、服务器全文搜索或永久删除。
