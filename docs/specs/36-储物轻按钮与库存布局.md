# 储物轻按钮与库存布局

反馈：`01a1becf-96aa-77ef-8a89-25b3a66b4747`。

## 按钮契约

- 共享 `packages/addons/lib/visual-tokens.cjs` 定义 `--wb-btn-*`：默认透明底、hover 当前色 6% 浅底、active 11% 底、32px 最小触控区、accent 2px 焦点环与 2px offset，以及主按钮背景/反色文字和危险文字色。颜色继承宿主主题。
- 储物基础按钮 `border:none`。卡片编辑/删除/多图展开、标签 chip、工具栏刷新/选择/排序/清除、分页、弹窗动作均复用同一状态规则。图片预览与描述展开按钮也无描边。
- 新增/保存主按钮为实心 accent；文字保留 `var(--dsw-alias-label-primary-inverted,#fff)`，hover/active 仍为实心强调色。
- 删除动作常态与普通动作同权重，只在启用且 hover 时变红；focus-visible 始终为 accent，不跟随危险文字色。disabled 不获得 hover/active 浅底或危险色。
- 配置页使用相同 token。共享数据样式工厂仅在 `DOMAIN === "storage"` 时统一所有 button（刷新/导出/分页/表头排序/筛选清除/表选择等）；不改变任务、站点、标签的数据页按钮。筛选清除按钮扩为 32px，输入右内边距相应增加。
- 表单输入框、选择框与内容卡片继续保留其边界；按钮规则不去除容器边界。

## 库存布局

卡片头部顺序固定为真实 Lucide `package` SVG、数量 span、单位 small。`inline-flex + align-items:center + gap:5px` 控制对齐和间距，不再使用 SVG 左右 margin 或文本前置空格。

`null`、`undefined`、空字符串显示“图标 —”，不显示库存单位。数字 `0`、字符串 `"0"` 是有效库存；存在单位时显示“图标 0 单位”。单位元信息仍可独立展示。
