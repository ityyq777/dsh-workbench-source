# 任务与站点树概览

对应反馈：01a1bea2-d873-7ee2-ada2-4d963c51c40d。

## 目标与范围

新增 taskNodes.overview / siteNodes.overview，供 agent 在创建记录前一次了解节点用途、类型、归属路径、记录量和近期使用情况。旧 tree / children / path 的行为不变。关联反馈 01a1bea0-61a3-7c5d-a8bd-79401c6f33d1 与待评审 spec29 的强制归属/创建规则不在本次范围。

任务节点有物理根（通常 id=1），类型沿用 0=group、1=table、2=root_group。站点目录的根 id=0 是虚拟节点、不输出；真实目录没有任务组/表区分，统一派生 type/typeName=folder，各层均可直接放站点与子目录。原 site_node 无 description 列，本次配套补齐目录描述的幂等迁移及 create/rename、备份/同步契约；overview 读取真实目录描述，不拼接站点内容充当描述。

## 参数与输出

两个 action 均只有一个可选输入 maxDescriptionLength：非负安全整数（0..9007199254740991），按 Unicode 码点截断描述，省略时返回全文。0 返回空描述正文；非空原描述的 descriptionTruncated=true。负数、小数、字符串、null 均报错。参数同时影响结构化结果与文本，不限制节点数。

返回：

- nodes：根节点数组，递归 children；按同层 sort、id 升序。
- total：从根可达且祖先均未删除的节点总数；不包含孤儿、已删节点及其后代。
- returned：本次返回的节点总数，当前等于 total。
- truncated：是否截掉节点；当前全量返回，恒 false，包括超过百个节点。
- descriptionTruncated：是否有任一节点的描述因显式 maxDescriptionLength 而被缩短，与 truncated 分开。

每个节点字段：

| 字段 | 语义 |
| --- | --- |
| id / name | 节点 ID 与名称 |
| type / typeName | 任务保留数字字符串类型码并附英文可读名；站点均为 folder |
| description | 默认全文；只在调用方显式传上限时截断 |
| descriptionSupported | true，两侧均读取实际描述字段 |
| descriptionTruncated | 当前节点描述是否被截断 |
| path | 根到自身的面包屑数组，每段含 id/name/type；站点不包含虚拟根 |
| count | 当前节点及其可见后代的未删除任务/站点总数；任务包含全部状态，站点按 site.id 去重 |
| directCount | 直接归入当前节点的未删除记录数，站点同样去重 |
| lastUpdatedAt | Unix 毫秒；当前节点及可见后代节点、未删除记录的 updated_at 最大值；站点还包含连接有效站点的未删除目录映射 updated_at。空节点退回节点更新时间，不代表访问时间 |
| canContainRecords | 任务仅 table=true，group/root_group=false；站点 folder=true |
| children | 直接子节点数组，叶节点为 [] |

历史遗留直接挂在任务组的记录仍纳入统计，canContainRecords 表示合法写入语义，不替代数据修复。已删记录、已删映射、无效目录与孤儿记录不纳入 count；同一站点同时挂父子或兄弟目录，祖先 count 只计一次。因此站点 count 不一定等于 directCount 加各子 count。

## 文本与可发现性

文本输出缩进树、名称、类型、可放记录提示、子树计数、id、完整面包屑、更新时间和描述全文。任务组明确写“只能装子节点，不能直接放任务”，任务表写“可直接放任务”；站点写“目录，可直接放站点和子目录”，计数标注去重。

宿主 capabilities.get 的任务/站点静态 capability relations/notes 指引“先 overview 再 create，不要凭感觉选节点”，primaryAction 仍为实际创建动作。不存在 tasks.capabilities，不为此杜撰新动作。已有 sites.capabilities 保留 tags 布尔值，附加 overviewAction=siteNodes.overview 和 placementGuidance，并同步文本说明。

## 实现与性能

两个包各有独立 overview 模块，由 index.setup 注册，不扩张旧 tree 或 tasks 主模块。每次 overview 固定两次只读 SELECT：第一条递归取可见节点；第二条递归构建祖先/后代关系，GROUP BY 祖先聚合 count/directCount/lastUpdatedAt。站点使用 COUNT(DISTINCT site.id)，无需逐节点查询。内存按邻接表组装树与面包屑。不增加计数缓存列或生产数据写入。

闭包计算成本与祖先/后代对数量相关，深链最坏为平方级；当前面向几十至数百节点的全量导航。total/truncated 如实告知全量结果，没有隐含 100/200 节点截断。

## 跨版本快照兼容边界

新端会在站点插件初始化时幂等补齐 site_node.description。旧备份缺 description 时按空串恢复：overwrite 会清空对应节点的现有描述；newest 在旧备份节点更新时间较新、该行被选中写入时也会清空。旧远端树快照的合并规则不同：远端缺 description 时保留已有本地描述，没有本地描述才补空串；远端显式空串则可清空。不要把备份恢复与远端快照合并的缺字段语义混用。

反方向不等价：旧宿主 replaceRows 按 Object.keys 直接生成 INSERT，未迁移的旧端接收含 description 的新快照会因缺列失败。因此参与同步或恢复新快照的接收端必须先升级站点插件并完成初始化迁移，再同步/导入；不能宣称新快照可直接回灌未升级旧端。本次不改宿主 replaceRows，也不对生产库执行手动迁移。

## 验证与集成

独立运行 node scripts/test-node-overview.mjs：内存 SQLite，覆盖两侧超过 60 字的完整描述与截断参数、分组子树计数、所有任务状态、空节点、软删除与不可见后代、孤儿、站点跨目录去重、时间戳、百级节点、两次查询预算、legacy 接口不变以及静态/动态能力发现。

任务和站点包 toolActions 分别增加 taskNodes.overview / siteNodes.overview，版本为 tasks 2.11.0、sites 1.9.0；包版本、客户端源和生成物、全局功能清单已同步。统一构建、schema/行数审计、e2e、config/nodeps 和发布树生成通过。

异常备份可能含真实 id="0" 行，修复前会触发递归查询不终止。两侧查询现显式排除虚拟根 ID，并以 UNION 去重防护；独立子进程回归覆盖 id0 自环、孤立自环、双节点环和虚拟根后代回边，正常树仍全量返回且维持两次查询。独立复审使用原始异常备份重现脚本，确认查询立即返回空树，不再超时。
