- 统计、记录、配置、数据四视图统一使用现有 lucide-react 依赖，不另引图标库。使用其公开 `lucide-react/icons/*` 子路径按需导入，最终未压缩分发包 174,164 字节；避免从总入口引入整库（原为 2,304,093 字节）。视觉测试限制内存包小于 250,000 字节且图标模块不超过 30 个，防止体积回归。
- 数据页继续委托共享 data-view 工厂。新增可选 Icon / Skeleton 渲染配置，其他域不传参数时保留原行为；没有复制数据页实现。

- 任务仅在样式侧接入公共 token，不触及任务组件实现。

## 图标与交互

storage 的 ICONS 映射涵盖模块、统计、记录、配置、数据、搜索、刷新、排序、库存、品牌、单位、图片、标签、编辑、删除、重置等用途。

Icon 默认 14px；常规允许 11 / 14 / 16px，strokeWidth=2，aria-hidden=true，focusable=false。仅 empty 图标允许 48px。

模块 header 使用图标+标题；工具按钮使用图标+文本。记录、统计、配置头部在 480px 以下容器中隐藏操作文本，保留 aria-label 与 title。共享数据刷新按钮在 480px 以下窗口中采用同样方式。编辑/删除始终为 32×32 图标按钮，名称包含目标物品名。

品牌/单位为 muted 小图标；库存、标签和图片按钮分别有语义图标。图片按钮背景保留占位图标，正常图片覆盖其上。空态使用 48px package-open 与可操作的引导文案。

## 宿主 tabs 的真实契约

宿主 0.5.7 新增可选 views[].icon 函数组件契约；storage 注册包装函数并转发图标属性。旧宿主忽略额外字段仍能显示文本标题，但完整图标体验需要 0.5.7，storage 的 minShell 已同步声明。详见 [视图图标契约](./35-视图图标契约.md)。

## Token、加载与动效

公共 visual-tokens 提供：8px 小圆角、12px 卡片圆角、8/14px 间距、主题边框、描述背景及左边框、140ms 过渡。储物、任务卡片和共享数据容器复用；描述底色使用主题品牌色轻混合。

记录、统计、配置与 storage 数据页首次加载显示三张卡片骨架；共享数据行加载与索引加载也可使用该适配器。图标/按钮有 hover、focus-visible 与 disabled 状态；reduced-motion 关闭骨架动画与过渡，卡片不再上浮。
