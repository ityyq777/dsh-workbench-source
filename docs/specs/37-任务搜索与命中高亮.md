# 任务搜索与命中高亮

反馈：`01a1bebd-d37b-7d9d-9777-12b7605a70dd`。任务插件源码版本 2.12.0。

## 搜索契约

- `tasks.list.titleKey` 去除两侧空白后，同时对标题 `title`、描述 `description`、感受 `review` 做 LIKE 包含查询，三个字段之间 OR，与其它筛选项 AND。空关键词不增加条件。
- 复用现有 `%`、`_`、反斜杠转义及 SQL 绑定参数；这些字符按字面匹配，不作为通配符。ASCII 大小写不敏感；不承诺 SQLite 默认 LIKE 之外的 Unicode 折叠。
- 分页查询与 `total` 使用同一 WHERE；`returned`、`truncated`、排序、默认分页和上限不变。
- `tasks.export` 非空 `ids` 优先，否则复用同一查询。共享筛选 schema 避免参数能用却不可发现。保留原导出范围：tab 5..8（包括缺省总览）默认 12 条，其他 tab 最多 500 条；不增加分页参数，不把此次修改变成全量导出改造。
- `tasks.dataQuery.search` 保持所有 TEXT 列搜索，包括标题、描述、感受、ID 等。此入口仍有原关键词长度上限，不缩减为三个业务字段。
- 同步 action schema、capability 字段说明、中英文搜索提示。

共享筛选字段：`tab,titleKey,tableId,groupId,tableKey,filterRestarted,checkedTypes,tags,status,priorityMin,priorityMax,targetFrom,targetTo,tagIds,sort,order`。list 另有 `pageNumber,pageSize`；export 另有 `format,ids`。

## 前端

`Highlight({text,keyword})` 使用转义后的字面正则，仅将 ASCII 字母扩为大小写字符对，不使用 JavaScript 的 `i` 标志；与 SQLite LIKE 一致，`É/é`、`Σ/σ` 不互相匹配。保留原文本大小写；空关键词或未命中直接返回文本。只生成 React 文本节点和 `mark.wbt-hit`，不解析 HTML，不插入 innerHTML。

列表、卡片共用 TaskItem，标题、描述、感受都接入已提交的 `titleKey.trim()`，不会跟着尚未提交的搜索草稿变色。mark 无交互事件、不阻止冒泡，双击依旧进入原字段编辑。编辑器显示原文，blur/键盘保存逻辑不变。保留文本容器和既有换行、截断、布局规则，不增删展开状态；当前任务描述本来是换行展示，没有独立展开按钮。

任务根节点独立定义 `--wbt-hit-bg:#ffe4e6`、`--wbt-hit-fg:#881337`，明暗主题均使用同一对明确颜色，对比度约 7.97:1，超过 4.5:1。mark 继承字体且零内边距，降低对换行/截断的影响。含命中的关闭卡片恢复 opacity:1，避免父元素透明度使对比度失效；未命中的关闭卡片仍保留既有弱化。未修改共享视觉 token。
