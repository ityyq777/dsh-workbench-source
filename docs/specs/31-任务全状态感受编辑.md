# 任务全状态感受编辑

反馈：01a1bea8-165b-7721-afaa-fdd4fe115b1d。

## 行为

- status 0（开启）、1（关闭）、2（完成）、3（重启）均可编辑感受。
- EditModal 在描述下始终显示独立感受输入框，包括当前没有感受时；保存时独立比较 review，变化才提交，空串表示清空，未变化则不携带 review。
- 难度仍仅已完成可改；未完成优先级编辑规则保持原样。
- 卡片与列表共用 TaskItem，已有感受可双击编辑，不再检查完成状态；空感受通过编辑按钮进入弹窗新增。
- 完成弹窗预填现有感受，避免之前已经记录的感受被默认空串覆盖。用户主动清空仍生效。
- 中英文说明均明确任何状态可记录感受，难度仅完成后可改。

## 代码边界

EditModal 抽入独立工厂模块 client/edit-modal.cjs，通过入口传入 React、statusInfo、stars，原 props 与调用接口不变，无循环依赖。入口冻结预算由 1474 降至 1383（审计按换行拆分含末尾空行计算）；仅抽本次编辑职责，其余视图不改。

后端已有 PUT_TYPES.REVIEW = "4"，字符串 REVIEW 和数值字符串 "4" 均为合法 type。review 字段 patch 与专用 REVIEW 均支持空串，无需修改后端。重启创建新任务时，已完成源任务保留完成状态与感受；未完成源任务按已有规则转为重启状态。本次不改变该语义，不要求新任务继承源任务感受。
