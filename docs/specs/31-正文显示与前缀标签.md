# 正文显示与前缀标签

2026-11-09：任务描述与感受、储物卡片描述共用正文组件。

## 显示与编辑

- 默认 Markdown；每个描述、感受块上方各有无边框图标按钮，具备 title、aria-label、aria-pressed，可独立切换 Markdown / 纯文本，不影响另一块或其他任务。
- 任务、储物各自的配置页「正文显示模式」决定本域新挂载正文块的初始模式；已挂载块保留自己的选择。储物版本 1.4.1。
- 标题、描述与感受区域仅展示文本，不提供双击编辑、局部铅笔或编辑提示。点击任务操作区的「编辑」按钮打开统一编辑面板，在标题 input 和描述、感受两个 textarea 中修改原文并用面板保存按钮提交；Markdown 标记原样保留。任务所有状态均沿用面板的既有编辑规则。文本区域均不支持双击编辑；状态和优先级快捷操作保留；储物描述保留原有展开/收起。
- 描述小标题为「描述」/「Description」，感受为「感受」/「Reflection」，位于各自正文块外上方，与切换按钮同排。空正文不显示标题和按钮。
- 任务、储物小标题为正文外真实 span：11.5px、600、.06em 字距、.72 透明度，使用主题文字色，无胶囊背景；左侧与正文文字对齐，切换按钮位于同排右侧。标题至正文 4px，任务正文块之间 10px。
- 共享切换按钮为 24×24px、无边框、.7 透明度，hover 背景 5%、focus-visible 2px 轮廓。图标表达当前模式：Markdown 为 code-2，纯文本为 pilcrow，切换淡入 140ms；尊重 reduced-motion。aria-pressed=true 明确表示 Markdown 模式。title 与 aria-label 使用双语 copy 模板，包含字段名、当前模式与切换目标。
- section 使用 aria-labelledby 关联唯一标题 ID；优先 React.useId，旧测试 mock 回退组件 state。正文区域 overflow-anchor:none，避免模式切换触发滚动锚点跳动。
- 搜索高亮只作用于解析后的文字叶子，代码文字也可高亮，但不解析代码内 Markdown，不修改链接 href。

## 配置契约

通过 tasks.configOptions / tasks.configGet 发现 ui.bodyMode：enum，默认 markdown，仅允许 markdown、text。tasks.configSet 参数示例：

```json
{"values":{"ui.bodyMode":"text"}}
```

配置仅存本机 meta 的 config.tasks.ui.bodyMode，不进入同步与备份。tasks.configReset 的 ids 包含 ui.bodyMode 可恢复默认；省略 ids 重置全部配置。未知值整批拒绝。

每块切换只保留在当前组件状态，不写配置或浏览器存储，重新挂载使用配置初始值。配置页继续负责保存/重置默认值，不广播全局模式，使用请求锁避免旧响应覆盖新值；不协调不同浏览器的并发写入。


储物独立安装无任务接口依赖：storage.configOptions / configGet 提供 ui.bodyMode（markdown/text，默认 markdown）；storage.configSet / configReset 保存或重置本机 config.storage.ui.bodyMode。记录视图读取此值，经 StorageCard 传入 Description 作为首次挂载初始值。Description 使用本地独立 state，不读取 localStorage、不订阅全局 useMode。任务配置与正文切换不影响储物，储物切换不影响兄弟卡片。展开/收起状态独立于正文模式。

## 支持的 Markdown 子集

- 段落、硬换行、h1–h6 标题、引用与水平分隔线。
- 星号粗体/斜体、单反引号行内代码、三反引号围栏代码块；围栏内容完全按字面显示。
- 有序/无序列表及一层缩进嵌套。
- 行内链接仅接受显式 http://、https:// 或 mailto:；新窗口并设置 noopener noreferrer nofollow。
- 常用 Markdown 标点支持反斜杠转义。未闭合围栏、未知语法和原始 HTML 按字面显示；不支持图片、表格、任务框、HTML 执行或完整 CommonMark。

使用 React 文本节点和受控标签，不使用 HTML 注入。协议校验拒绝控制字符及编码/实体伪装的危险协议。缓存按源文本和模式区分，最多 100 项、合计 100 万键字符，超过 10 万字符的正文不缓存；解析的行内与块嵌套均限制深度。
