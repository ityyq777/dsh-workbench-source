# 正文显示与前缀标签

2026-11-09：任务描述与感受、储物卡片描述共用正文组件。

## 显示与编辑

- 默认 Markdown；任务记录工具栏 M/T 分段按钮具有 title、aria-label 与 aria-pressed，同时切换描述和感受。
- 任务配置页的「正文显示模式」使用相同配置，保存与恢复默认会同步当前窗口的卡片。
- 标题、描述与感受区域仅展示文本，不提供双击编辑、局部铅笔或编辑提示。点击任务操作区的「编辑」按钮打开统一编辑面板，在标题 input 和描述、感受两个 textarea 中修改原文并用面板保存按钮提交；Markdown 标记原样保留。任务所有状态均沿用面板的既有编辑规则。文本区域均不支持双击编辑；状态和优先级快捷操作保留；储物描述保留原有展开/收起。
- 描述前缀为「描述」/「Description」，感受为「感受」/「Reflection」，空正文不显示前缀。前缀不参与双击编辑。
- 前缀为真实 span：11px、600、.06em 字距、4px 圆角、1px 4px 内边距；描述使用蓝色，感受使用主题强调色的 8% 背景。浅色不透明胶囊底保证深浅主题文字对比度均至少 4.5:1，不依赖正文背景色。
- 搜索高亮只作用于解析后的文字叶子，代码文字也可高亮，但不解析代码内 Markdown，不修改链接 href。

## 配置契约

通过 tasks.configOptions / tasks.configGet 发现 ui.bodyMode：enum，默认 markdown，仅允许 markdown、text。tasks.configSet 参数示例：

```json
{"values":{"ui.bodyMode":"text"}}
```

配置仅存本机 meta 的 config.tasks.ui.bodyMode，不进入同步与备份。tasks.configReset 的 ids 包含 ui.bodyMode 可恢复默认；省略 ids 重置全部配置。未知值整批拒绝。

工具栏切换立即更新同源 localStorage 的 wb.bodyMode 和当前窗口事件；随后请求 tasks.configSet。保存失败会明确提示「已在当前浏览器切换，配置保存失败」，不声称服务端持久化成功。下次任务页挂载以成功读取的配置为准；配置读取失败时沿用本地偏好。其他标签页通过 storage 事件同步。

配置页保存/重置/读取使用同一组件内同步请求锁，保存期间禁用控件，旧渲染事件也不能提交第二个请求；工具栏切换使用相同的单请求策略。失败（含同步异常）释放锁。配置页卸载后旧保存响应不再广播覆盖当前正文模式。此锁不协调不同组件实例、浏览器或 agent 的并发配置写入；重挂载以再次读取的服务端值为准。

储物独立安装无任务接口依赖：默认 markdown，只读取同源本地偏好并监听变化，不调用任务域。没有本地缓存也不写任务配置。浏览器禁止 localStorage 时仍能在当前已挂载视图切换，但刷新后不能依靠本地偏好恢复。

## 支持的 Markdown 子集

- 段落、硬换行、h1–h6 标题、引用与水平分隔线。
- 星号粗体/斜体、单反引号行内代码、三反引号围栏代码块；围栏内容完全按字面显示。
- 有序/无序列表及一层缩进嵌套。
- 行内链接仅接受显式 http://、https:// 或 mailto:；新窗口并设置 noopener noreferrer nofollow。
- 常用 Markdown 标点支持反斜杠转义。未闭合围栏、未知语法和原始 HTML 按字面显示；不支持图片、表格、任务框、HTML 执行或完整 CommonMark。

使用 React 文本节点和受控标签，不使用 HTML 注入。协议校验拒绝控制字符及编码/实体伪装的危险协议。缓存按源文本和模式区分，最多 100 项、合计 100 万键字符，超过 10 万字符的正文不缓存；解析的行内与块嵌套均限制深度。
