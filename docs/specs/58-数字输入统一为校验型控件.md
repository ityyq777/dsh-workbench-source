# 58 · 数字输入统一为「自由输入 + 红字校验」，并抽出共享 NumberField

> 状态：已实施（2026-11-21）。
> 目标版本：涉及插件各一个 patch（见 §5）。
> 关联：[04-UI规范](../AGENTS规范/04-UI规范.md)、[57-布尔开关统一](57-布尔开关统一与共享Switch组件.md)。

## 0. 一句话结论

插件里的数字输入以前是 `<input type="number" min=… max=…>`，不少地方还「每次按键就保存」，
后端再把值静默夹回边界——用户刚打到第三位就被换回 1 或 500，根本没法输入。本次统一为
`packages/addons/lib/number-field.cjs`：纯文本 + `inputMode`，范围只作提示，非法/越界显示红字
且**不提交、不改写**，表单场景同时禁用保存；19 处调用点全部接入。

## 1. 问题机制（改动前）

| 症状 | 根因 | 典型位置 |
| --- | --- | --- |
| 输入被自动换成边界值 | 后端 `Math.min/Math.max` 静默夹取，返回值再回填输入框 | `automation/lib/domain/rules.js:154-155`（maxRules 1–500、perHour 1–600）、`danmaku/lib/config.js:228`、`mail/lib/domain/auto-sync.js:40-41` |
| 打进第三位就跳回 | 每次按键 `onChange` 就 `save()`，保存结果回灌 | `message/client/views/config.cjs:205`、`mail/client/views/config.cjs:146-172` |
| 表单里越界值被 clamp 掉 | 输入期 `Math.max(0, Math.min(5, …))` | `tasks/client/item/difficulty-field.cjs:11`、`tasks/client/modals/create-modal.cjs` 的 `clampInputPriority` |
| 样式简陋、有原生步进箭头 | 直接用 `type="number"` | 其余各处 |

## 2. 交互决策（用户确认，2026-11-21）

1. 越界/非法：**红字提示 + 禁止保存**，绝不悄悄改用户输入；
2. 输入框改纯文本 + `inputMode`（整数 `numeric`、小数 `decimal`），丢掉原生步进与 min/max 回灌；
3. 覆盖「全部插件内可编辑数字项」：设置页配置项 + 业务表单（优先级、难度、时长、端口、金额、筛选上下限）。

后端 clamp 保留，作为绕过界面的 API 的最后一道兜底；界面层不再产生越界值，所以不会再出现「被改回去」。

## 3. 共享组件契约

`packages/addons/lib/number-field.cjs` 导出 `{ NumberField, validateNumber, rangeHint, messages, styles }`。

- `NumberField({ h, lang, value, min, max, step, integer, disabled, unit, hint, placeholder, ariaLabel, title, wide, className, onCommit, onValidChange, onDraft })`
  - 内部维护 draft；**只在失焦 / 回车**且校验通过时 `onCommit(数值)`；非法时渲染 `.wbctl-num-err`（`role="alert"`）并保留用户输入。
  - `Esc` 撤销回外部值；`onValidChange(ok, err)` 把合法性交给父表单禁用保存。
  - 外部 `value` 变化时回填 draft，但输入框聚焦期间不打断（避免光标跳走）。
  - 范围提示由 `rangeHint()` 生成，例如「1–500，整数」「0–5，步长 0.5」；传 `hint:false` 可关闭。
- `validateNumber(raw, { min, max, step, integer, allowEmpty, lang })` → `{ ok, value, error }`；
  文案中文/英文双语（`messages('zh'|'en')`），整体表单校验与测试复用同一套规则。
- `styles`：固定类名 `wbctl-num*`，颜色只取 `--wb-surface/--wb-line/--wb-border/--wb-accent/--wb-danger/--wb-muted`，
  含 `:focus`、`.is-invalid`、`:disabled`、`prefers-reduced-motion`。
- `client-common.cjs` 额外暴露 `NumberField`、`numberFieldStyles`、`validateNumber`。

样式注入：插件样式表末尾 `.concat(NF.styles)`（重复追加无害）。`automation` 仍注入到真正下发的
`client/ui/styles.cjs`（版式层禁止 hex/rgba 的既有约束）。

## 4. 迁移清单（19 处）

设置页配置项（`item.type === "int"`）：tasks、tags、sites、storage、message、mail、automation（2 处）、danmaku。

业务表单：tasks 新建/编辑优先级（1–10 整数）、难度（0–5，步长 0.5，空 = 未设置）、筛选面板上下限、
