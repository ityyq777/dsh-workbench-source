# 自动化插件 UI 设计（automation 0.2.0）

> 状态：设计已定稿，随 0.2.0 实现。范围：`packages/addons/automation/client/` 的
> 概览（stats）、规则（rules）、运行记录（runs）、设置（config）四个视图与样式基座；
> 数据（data）、Action（actions）两个共享视图不动，只保证继承新基座后不破。
>
> 背景：0.1.0 的自动化页面是"能用的表单堆叠"——面板/卡片/表格容器没有样式，空态与
> 表头同时出现，新建表单挤在表格下方、两个 JSON 框按默认 cols 渲染成窄条。本轮先定
> 设计再实现，不接受只补几条 CSS。

## 1. 设计原则

1. **token 唯一**：颜色、边框、阴影、遮罩只取 `--wb-*` 与 `--dsw-alias-*`；插件内
   零字面色值。浅色/深色靠 token 自动跟随，不写 `prefers-color-scheme` 分支。
2. **全宽**：`.wba-wrap` 撑满可用区域，只保留统一内边距，不收窄居中。
3. **先复用共享件**：按钮/字段/提示/空态/JSON 用 `packages/addons/lib/client-common.cjs`
   （前缀注入 `wba`）；本插件只补它没有的版式类。
4. **文案全走 `props.lang`**：规则页、编辑器、运行记录、设置四块文案进
   `client/ui/copy.cjs`（zh/en），组件内不出现中文字面量。
5. **状态显式**：加载（骨架）、空（一张空态卡）、错误（notice）、有数据（表格）四种
   状态互斥，空态时**不渲染表格**。

## 3. 概览（stats）

```
┌ 自动化 ──────────────────────────────── [刷新] [新建规则] ┐
│ 轻量触发：白名单 action、模板、条件、限频                     │
├ 5 × KPI 卡（auto-fit ≥160px）────────────────────────────── ┤
│ [icon] 规则总数  [icon] 已启用  [icon] 今日成功  …失败  …跳过 │
│  说明：全部未删除规则 / enabled=1 / 近 24h 按 status 汇总      │
├ 能做什么 + 限频口径（panel）────────────────────────────────┤
│ 允许调用：chips（5 个白名单 action）                          │
│ 不允许：chips（vault.* / automation.* / audit.* / 删除/备份） │
├ 触发器说明（panel）───────────────────────────────────────┤
│ interval / dailyAt / event / manual 四行说明                 │
└────────────────────────────────────────────────────────────┘
```

- KPI 口径写在每张卡的副行（12px muted）：规则总数=未删除规则；已启用=enabled=1；
  今日成功/失败/跳过=近 24 小时 `automation_run.status` 计数。
- 白名单分两组 chips：允许（`opts.actions`）与禁止（固定文案，来自后端 `DENIED` 规则）。
- 「新建规则」跳转到规则页并直接打开编辑器（通过 props 回调由 client.src.cjs 注入
  `onNewRule`，缺省只切换视图）。

## 4. 规则页（rules）

### 4.1 有数据

```
┌ 规则 ─────────────────────────────── [刷新] [+ 新建规则] ┐
│ 副标题：定时 / 域事件 / 手动触发；只能调用白名单 action；每规则每小时限频 │
├ 过滤条 ────────────────────────────────────────────────┤
│ [搜索名称或 action] [状态▾] [触发方式▾] [清除]             │
├ 表格（.wba-table-wrap）─────────────────────────────────┤
│ 名称        触发方式        执行 Action   状态   上次运行     操作 │
│ 每日提醒     ⏱ 每 60 分钟   message.send  启用   11-15 09:00   ▶ ✎ ⏻ 🗑 │
│ rule_xxx                                  上次成功                  │
└────────────────────────────────────────────────────────┘
```

列定义：

| 列 | 内容 | 说明 |
| --- | --- | --- |
| 名称 | `name` + `.wba-mono` 弱化 id | 名称过长单行省略，title 展示全名 |
| 触发方式 | 图标 + 文本（`triggerText`） | 图标：interval→timer、dailyAt→alarm-clock、event→radio、manual→hand |
| 执行 Action | `<code>` 等宽 | 过长省略 |
| 状态 | pill：启用=ok、停用=中性 | 同时显示 `lastStatus` 的语义 pill 在「上次运行」列 |
| 上次运行 | `lastRun.startedAt` 时间 + 结果 pill（ok=ok/error=error/skipped=warn/无记录=—） | 时间用 `C.fmtTime` |
| 操作 | 运行、编辑、启停、删除（图标按钮，title 带本地化文案） | 删除二次确认：`window.confirm` 文案含规则名；运行中禁用运行按钮 |

过滤：搜索匹配名称或 action 名（大小写不敏感）；状态（全部/启用/停用）；触发方式
（全部/间隔/每天/事件/手动）。过滤在客户端完成（规则 ≤200 条，不做服务端分页）。
过滤后为空但原本有数据时，显示"没有匹配的规则"空态卡（带「清除过滤」），**同样不渲染表格**。

### 4.2 空态（无任何规则）

只渲染一张 `.wba-empty-card`：zap 图标 36px + 标题 + 一句说明 + 「新建规则」主按钮 +
次行弱化说明「规则可随备份导入导出；运行记录只在本机」。表格、表头、分页都不出现。

### 4.3 加载与错误

加载：`table-wrap` 内渲染 3 行骨架（每行 6 个 `.wba-skel`），或第一屏用卡片骨架；
错误：`C.Notice` error + 重试按钮。

## 5. 规则编辑器（模态）

```
┌ 新建规则 / 编辑规则                                       ✕ ┐
│ ── ① 基本信息 ─────────────────────────────────────────── │
│ 名称 [______________________]        启用 [switch]         │
│ ── ② 触发 ─────────────────────────────────────────────── │
│ [间隔][每天][事件][手动]  ← segmented                       │
│ 间隔：每 [60] [分钟▾]                                       │
│ 每天：[09:00] 时区 [Asia/Shanghai▾] 星期 [一][二][三][四][五] │
│ 事件：域 [wb-addon-connector▾/datalist] 事件 [item.created]  │
│ ── ③ 执行 ─────────────────────────────────────────────── │
│ Action [message.send▾]  [查看参数示例] [插入变量▾]          │
│ ┌ JSON（width100% 等宽 min-height 160）────────────────┐   │
│ │ {                                                    │   │
│ │   "title": "自动化提醒"                               │   │
│ └──────────────────────────────────────────────────────┘   │
│ 非法 JSON → 红框 + 错误文案                                  │
│ ── ④ 条件（可选）───────────────────────────────────────── │
│ [switch 启用条件]  op: eq/neq/contains/gt/lt                 │
│ ┌ JSON min-height 96 ──────────────────────────────────┐   │
│ └──────────────────────────────────────────────────────┘   │
├ 底部 sticky：[取消] [保存]（JSON 非法或名称空时禁用）───────── ┤
└────────────────────────────────────────────────────────────┘
```

字段与状态：

| 段 | 字段 | 类型/约束 | 空与错误 |
| --- | --- | --- | --- |
| ① | 名称 | 1–80 字，必填 | 空时红框 + 「名称不能为空」，保存禁用 |
| ① | 启用 | switch（checkbox） | — |
| ② | 触发类型 | segmented 四选一：interval/dailyAt/event/manual | 切换**保留**已填内容（四个子表单各自独立存值，提交时只取当前类型） |
| ② | everyMinutes | 数字 1–10080 + 单位 select（分钟/小时，小时×60 归一） | 非数字/越界提示 |
| ② | time | `<input type="time">` HH:MM | 格式非法提示 |
| ② | tz | select：Asia/Shanghai、UTC、Asia/Tokyo、Europe/London、America/New_York（可手填） | 空时提示 |
| ② | weekdays | chips 1–7 多选 | 全不选=每天，提示文案说明 |
| ② | domainId/event | input + datalist（wb-addon-connector/wb-addon-message/wb-addon-tasks；item.created/message.sent/task.created） | 空时提示 |
| ③ | actionName | select（白名单 actions） | — |
| ③ | actionArgs | JSON 编辑器 | 实时解析；非法红框 + 「第 N 行…」；合法时格式化按钮可用 |
| ④ | condition.on | switch | 关闭时提交 null |
| ④ | condition JSON | `{field,op,value}` 编辑器 | 同上；字段名提示 event.item.x / item.x |

交互：

- **模板变量插入**：③ 段正文下方 chips `{{rule.name}}`、`{{rule.id}}`、`{{event.at}}`、
  `{{event.item.title}}`、`{{item.title}}`、`{{item.url}}`，点击插入到光标处；
  菜单用 `.wba-chip` 组，不弹层。
- **参数示例**：按 action 展示内置示例（message.send / tasks.create / tags.create /
  sites.create / connector.sourceRun），点击「填入示例」替换当前 JSON（覆盖前 confirm）。
- **未保存关闭**：点 ✕、点遮罩、按 Esc 时，若表单与初始快照不同 → `window.confirm(丢弃修改？)`。
- **Esc**：关闭（走同一脏检查）；打开时 `document.body.style.overflow="hidden"`，关闭恢复，
  组件卸载时清理，避免残留滚动锁。
- **保存**：校验通过后调用 `automation.ruleCreate` / `automation.ruleUpdate`，
  payload 与 0.1.0 一致（`triggerType` 映射 schedule/event/manual；`triggerConfig` 按类型）。

## 6. 运行记录（runs）

```
┌ 运行记录（最近 200 条）──────────────────────── [刷新] ┐
│ 副标题：只在本机保留，不随备份同步；点击行查看详情        │
├ 过滤：[规则▾] [状态▾]                                  ┤
├ 表格 ────────────────────────────────────────────────┤
│ 状态   规则      触发      开始         耗时    结果摘要   │
│ ▸ ok   每日提醒   schedule  11-15 09:00  0.3s   {"sent":1} │
│   ┌ 展开详情 ───────────────────────────────────────┐  │
│   │ id run_xxx ｜ 耗时 0.3s ｜ 开始/结束时间            │  │
│   │ 错误：—（红框仅在 error 时显示）                    │  │
│   │ 结果 JSON（.wba-code，只读 <pre>）                 │  │
│   └──────────────────────────────────────────────────┘  │
└───────────────────────────────────────────────────────┘
```

- 状态过滤在客户端完成（runList 入参只有 ruleId/limit）。结果 pill：ok/error/skipped/其它。
- 行展开：点击行切换；展开行用 `<tr><td colSpan=6>` 承载详情，详情含 run id、触发、
  开始/结束、耗时、错误（`color:var(--wb-danger)`）、result JSON。
- 空态：一张空态卡「还没有运行记录」+ 说明「规则运行后这里会保留最近 200 条」。
- 加载：3 行骨架。
- 页面标题旁注明「最近 200 条」，limit 固定 200。

## 7. 设置（config）

```
┌ 设置 ───────────────────────────────────────────┐
│ ┌ 限流（panel）────────────────────────────────┐ │
│ │ 规则数量上限 [50]   每规则每小时上限 [60]      │ │
│ │ 说明：1–500 / 1–600，超出时创建被拒或记 skipped │ │
│ │ [保存设置]  （保存后行内「已保存 HH:MM」）      │ │
│ └──────────────────────────────────────────────┘ │
│ ┌ 运行约束（panel）────────────────────────────┐ │
│ │ • 定时器每 30 秒检查一次，单次最多执行 3 条     │ │
│ │ • 全局并发 2，超出的定时触发记 skipped         │ │
│ │ • 事件触发 payload {domainId,event,data}       │ │
│ │ • 规则随备份迁移；运行记录只在本机             │ │
│ └──────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────┘
```

保存条：成功用 `C.Notice kind=ok`，失败 error；未修改时保存按钮可用但提示"无修改"或直接禁用
（本设计：表单值与已保存一致时禁用保存）。

## 9. i18n（copy.cjs）

结构：`{ zh: {...}, en: {...} }`，扁平 key（`rules.title`、`editor.section.trigger`、
`runs.empty.title`、`config.saved`），`t(lang, key, vars)` 支持 `{name}` 占位。
四块视图全部经 `t()` 取文案；`client.src.cjs` 已把 `lang` 注入 props。数据/Action 共享
视图不改。
