# UI 规范

> 从根 `AGENTS.md` 拆出的界面红线与桌面端布局规范。改布局、新增插件视图、调整主题时先读本文。

## 三条红线

### 1. 业务视图不要两侧留白

模块页容器（`wbc-wrap`、`wbv`、`wba-wrap`、`wbct-wrap`、`wbca-wrap`、`wbm-wrap`、
`wbm-page` 一类）不得用 `max-width` + `margin:0 auto` 居中收窄；宽度撑满可用区域，
只保留统一内边距。需要限制阅读宽度时，限制正文段落，不要收窄整个视图。

### 2. 桌面端顶栏只有一层，并直接占满系统标题栏区域

macOS（`html[data-platform=darwin]`）不再预留 `--dsh-frame-top-clearance: 48px` 的
垂直空白：`.wb-immersive` 与 `.wb-immersive-bar` 的 `padding-top` 只保留 8px，
顶栏背景从 `y=0` 连续覆盖；左侧用
`padding-left: max(88px, calc(12px + var(--dsh-frame-leading-clearance, 0px)))`
避开红绿灯与 leading 控件。

Windows 仍把 `--dsh-frame-top-clearance`（caption 高度）并入 `.wb-immersive-bar` 的
`padding-top`。

顶栏内**不得**声明 `-webkit-app-region: drag`。原生拖拽区会先于 DOM 命中，吞掉任务树
等覆盖层顶部的“管理模式 / 关闭 / 搜索框”点击；窗口拖动交给桌面端标题栏。视图标签
（`.wb-page-tabs`）必须并进同一行顶栏，不得在内容区再渲染第二行栏。顶栏用
`justify-content: space-between` 分左右两区：左区是插件图标、返回按钮和标签，标签紧接返回
按钮；右区是模块名和版本号，贴右显示。插件图标绝对定位在顶栏最左侧的空白区，不占
flex 宽度、不能把返回按钮挤走；标签保持紧凑，不拉伸；禁止为了填空白加描述，也禁止把每个标签 `flex: 1` 拉宽。

### 3. 样式必须跟随 DSH 主题

所有颜色、边框、阴影、遮罩必须来自主题 token，不允许写死浅色或深色值。

- 使用宿主统一 token：`--wb-card`、`--wb-border`、`--wb-line`、`--wb-surface`、
  `--wb-accent`、`--wb-muted`、`--wb-ok`、`--wb-warn`、`--wb-danger`；这些 token 由
  DSH 主题变量（如 `--dsw-alias-bg-layer-*`）派生，插件不要自建第二套色板。
- 禁止新增 `#fff`、`#000`、`#f5f6f8`、`#2563eb` 一类固定色作为大面积背景、文字或
  按钮色；确需半透明时用 `color-mix(in oklab, var(--wb-card) 86%, transparent)`，
  不要用固定的 `rgba(255,255,255,...)`。
- 新增组件必须同时具备浅色、深色下的背景、文字、边框、hover、focus、disabled 状态；
  深色下不能出现“白底卡片”或看不清的灰字。
- 插件视图继承 `.wb-root` 的 token，不按模块另设主题开关；主题由 DSH 统一切换。

## 标签查询控件

任务、站点、储物三处的标签筛选/选择控件共用同一套交互契约。三处各自实现自己的
`client/ui/tagfilter.cjs`（暂不抽公共包），改其中一处时要同步核对另外两处：

- 触发按钮显示「标签筛选」，有选中时追加 ` · n`；展开后搜索框自动聚焦。
- 关键词输入 200ms 防抖；关键词变化回到第 1 页，清空后立即回第 1 页。
- 每页 20 条；列表滚动到 `scrollTop + clientHeight >= scrollHeight - 24` 时请求下一页，
  追加前按 id 去重，防止触底事件重复触发造成重复项；没有下一页时底部显示「没有更多」。
- 已选标签单独成区块并置顶，每项带 × 可单个移除，另有「清空」清空全部；搜索与翻页
  都不能丢失已选（翻页后已选项仍要显示名称）。
- 文案三态：加载中… / 没有匹配的标签（有搜索词但无结果）/ 暂无标签（库里没有标签或
  标签域不可用）；标签域不可用或未启用时整个控件不渲染，不显示禁用态空壳。
- Esc 关闭菜单：输入框 `onKeyDown` 与 `document` 级监听都要有，避免焦点移出后关不掉。
- 数据源只用本插件注册的 action：任务 `tasks.tagOptions`、站点 `siteTags.search`、
  储物 `storageTags.search`；不要直连其他插件的接口。
- 颜色、边框、阴影、悬浮态全部用 `--wb-*` / `--line` / `--surface` 等主题变量。
- 窄栏（容器 < 480px）下菜单不再相对按钮浮出，而是改为左右各 8px、贴工具栏下沿的整栏
  菜单：按钮位于工具栏中间时，260px 浮层会以按钮右缘对齐而溢出容器左边界；改为整栏后
  无论工具栏是否换行都不会横向滚动。宽栏保持按钮下方 260px 浮层，并限制在容器内。

唯一允许的差异是展示字段：任务侧显示每个标签的使用数量（`total`），站点与储物不展示计数。

## 验证

不能只看普通浏览器：浏览器里 `--dsh-frame-top-clearance` 与
`--dsh-frame-leading-clearance` 默认为 `0`，会掩盖桌面端问题。

- 模拟 `data-platform=darwin`（clearance 48px、leading 120px）与 Windows
  （clearance 32px）截图；
- 在独立 profile 实机确认浅色、深色都只有一层顶栏；
- 确认任务树顶部控件可点击，不被顶栏或拖拽区吞掉；
- 确认页面没有横向溢出，760px 以下单列布局正常。

深色验证使用 DSH 主题开关：`html[data-ds-theme-source]` 与
`body[data-ds-dark-theme]` 同时切换，不能只改页面局部 class。

## 常见错误

- 给视图容器加 `max-width:1180px; margin:0 auto`，宽屏两侧出现大留白；
- 顶栏用 `padding-top` 预留给系统标题栏，形成一条与页面同色的空白带；
- 给整条顶栏或标题区加 `-webkit-app-region: drag`，按钮点不动；
- 写死 `#fff` 背景，切到深色主题后仍是白底；
- 只截浅色或只截浏览器，不模拟桌面端 clearance；
- 新增第二行视图标签，和顶栏叠成两层。
