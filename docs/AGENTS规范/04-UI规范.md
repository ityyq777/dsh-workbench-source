# UI 规范

> 从根 `AGENTS.md` 拆出的界面红线与桌面端布局规范。改布局、新增插件视图、调整主题时先读本文。

## 四条红线

### 1. 业务视图不要两侧留白

模块页容器（`wbc-wrap`、`wbv`、`wba-wrap`、`wbct-wrap`、`wbca-wrap`、`wbm-wrap`、
`wbm-page` 一类）不得用 `max-width` + `margin:0 auto` 居中收窄；宽度撑满可用区域，
只保留统一内边距。需要限制阅读宽度时，限制正文段落，不要收窄整个视图。

### 1.1 应用式布局用 `.wb-fill` 拿满高度

三栏/双栏工作区（列表 + 阅读面板这类“自己内部滚动”的页面）在根节点加 `wb-fill`，
宿主会把 `.wb-immersive-main` 的整块可用高度给它：

```js
h("div", { className: "myplugin-page is-split wb-fill" }, ...)
```

宿主规则：`.wb-immersive-main:has(.wb-fill)>.wb-inner{height:100%}`、
`.wb-inner>div:has(>.wb-fill){display:flex;flex-direction:column;height:100%;min-height:0}`、
`.wb-fill{flex:1 1 auto;min-height:0}`。加了 `wb-fill` 的页面自己负责内部滚动
（`overflow:auto` + `min-height:0`），不要再让外层 `.wb-immersive-main` 滚动；
普通内容页不要加，否则内容会被压进一屏、失去整页滚动。

### 2. 桌面端顶栏只有一层，并直接占满系统标题栏区域

macOS（`html[data-platform=darwin]`）不再预留 `--dsh-frame-top-clearance: 48px` 的
垂直空白：`.wb-immersive` 与 `.wb-immersive-bar` 的 `padding-top` 只保留 8px，
顶栏背景从 `y=0` 连续覆盖；左侧用
`padding-left: max(88px, calc(12px + var(--dsh-frame-leading-clearance, 0px)))`
避开红绿灯与 leading 控件。

Windows 仍把 `--dsh-frame-top-clearance`（caption 高度）并入 `.wb-immersive-bar` 的
`padding-top`。

顶栏内**不得**声明 `-webkit-app-region: drag`。原生拖拽区会先于 DOM 命中，吞掉任务树
等覆盖层顶部的“管理模式 / 关闭 / 搜索框”点击；窗口拖动交给桌面端标题栏。视图标签
（`.wb-page-tabs`）必须并进同一行顶栏，不得在内容区再渲染第二行栏。顶栏用
`justify-content: space-between` 分左右两区：左区是插件图标、返回按钮和标签，标签紧接返回
按钮；右区是模块名和版本号，贴右显示。插件图标绝对定位在顶栏最左侧的空白区，不占
flex 宽度、不能把返回按钮挤走；标签保持紧凑，不拉伸；禁止为了填空白加描述，也禁止把每个标签 `flex: 1` 拉宽。

### 3. 样式必须跟随 DSH 主题

所有颜色、边框、阴影、遮罩必须来自主题 token，不允许写死浅色或深色值。

- 使用宿主统一 token：`--wb-card`、`--wb-border`、`--wb-line`、`--wb-surface`、
  `--wb-accent`、`--wb-muted`、`--wb-ok`、`--wb-warn`、`--wb-danger`；这些 token 由
  DSH 主题变量（如 `--dsw-alias-bg-layer-*`）派生，插件不要自建第二套色板。
- 禁止新增 `#fff`、`#000`、`#f5f6f8`、`#2563eb` 一类固定色作为大面积背景、文字或
  按钮色；确需半透明时用 `color-mix(in oklab, var(--wb-card) 86%, transparent)`，
  不要用固定的 `rgba(255,255,255,...)`。
- 新增组件必须同时具备浅色、深色下的背景、文字、边框、hover、focus、disabled 状态；
  深色下不能出现“白底卡片”或看不清的灰字。
- 插件视图继承 `.wb-root` 的 token，不按模块另设主题开关；主题由 DSH 统一切换。

### 4. 先复用共享组件，不要复制

新增或改造插件视图前，先查 `packages/addons/lib/`，不要凭手感再写一套。当前可直接复用的
入口：

| 共享入口 | 用途 | 典型用法 |
| --- | --- | --- |
| `data-view.cjs` | 「数据」页：表切换、搜索、逐列筛选、排序、分页、行详情 | `createDataView({ domain, prefix, tables, columns, Icon, Skeleton, tablesLoader, query })` |
| `action-schema-view.cjs` | 「Action」页：按域展示 schema、必填/类型筛选、参数表、示例、原始 JSON | `createActionSchemaView({ domain, prefix })` |
| `client-common.cjs` | 客户端基础组件：`unwrap/call/errText/fmtTime/Btn/Field/Notice/Empty/Pill/Json/useLoad` | `createCommon(prefix)` |
| `client-base-styles.cjs` | 按前缀生成 wrap/head/card/grid/KPI/table/button/field/notice/pill/json 基础样式 | `baseStyles(prefix)`，专属样式用 `.concat()` 追加 |
| `tag-filter.cjs` | 标签筛选/选择控件：防抖搜索、滚动分页、已选置顶、Esc 关闭 | `createTagFilter({ action, classes, mapPage, renderSelected, … })` |
| `stats-charts.cjs` | 统计页自绘图表基件：Donut/BarList/StackedRows/Trend/Histogram/DataTable/RangeSwitch 等 | `makeCharts(prefix, { icons, styles, showNote })`，取色用返回的 `colors` |
| `icons.cjs` | 图标组件工厂：别名解析、尺寸、兜底、无障碍属性 | `create(prefix, { 别名: require("lucide-react/icons/x").default }, options)` |
| `overlay.cjs` | 对话框外壳：点遮罩关闭、Esc、Tab 焦点循环、关闭后焦点归位 | `createOverlay({ tag, maskClass, dialogClass, header, ariaLabelOf })` |
| `button.cjs` | 图标按钮：`aria-label`/`title` 补全与类名拼装 | `createButton({ prefix, Icon })` |
| `skeleton.cjs` | 骨架屏：三张占位卡片 | `createSkeleton({ prefix, text })` |
| `switch.cjs` | 布尔开关：`role="switch"` 按钮、开/关文案、禁用与键盘焦点，全部走 `--wb-*` token | `require("../../lib/switch.cjs").Switch({ h, checked, onChange })`；样式用 `switch.cjs.styles` 追加到该插件样式表 |
| `number-field.cjs` | 数字输入：纯文本 + `inputMode`、范围只作提示、非法红字且不提交、失焦/回车才保存，全部走 `--wb-*` token | `require("../../lib/number-field.cjs").NumberField({ h, lang, value, min, max, integer, onCommit })`；样式用 `number-field.cjs.styles` 追加；校验逻辑复用 `validateNumber()` |
| `icon-label.cjs` | 共享图文标签：装饰性 Lucide 图标、统一尺寸和换行，保留可见文字 | `iconLabel(h, Icon, text)`，样式通过 `iconLabel.styles` 追加 |
| `vault-lock.cjs` | 保险箱锁定门禁：4 秒轮询 `vault.status`、锁定卡与样式、默认 fail-closed | `create({ prefix, wrapClass, Icon, title, hint })` → `{ use, Panel, gate, styles }` |
| `legacy-data.cjs` | 旧 `dataQuery`（只支持 limit/offset）到共享数据视图的适配层 | `createLegacyData(domain, { paged, maxRows })` |
| `date-picker.cjs` + `date-picker-styles.cjs` | 日期控件：单日、起止区间、按月、内联月历（见下文「日期控件」） | `DatePicker/RangePicker/MonthPicker/InlineCalendar` + `datePickerStyles(prefix)` |

判定规则：

- 同一个视图模式或交互在两个以上插件出现，就必须抽到 `packages/addons/lib/`；禁止复制整段
  文件后只改 `wbc`/`wbv`/`wbm` 前缀。
- 共享组件只通过 `domain`、`prefix`、`tables`、`columns`、`Icon`、`Skeleton`、
  `tablesLoader`、`query` 这类参数接收上下文，**不得 import 任何具体业务插件**，也不得
  把某个模块的文案、字段或业务规则写死进去。
- 业务专属布局留在插件内，通过传入列定义、图标、空态组件或 `.concat()` 追加样式扩展；
  不要为了复用把专属差异塞进共享组件的 `if` 分支。
- 修改共享组件必须回归全部使用方：至少跑 `pnpm build`、`pnpm test:clients`、ESLint，
  并实机抽查 tasks/sites 与六个新插件的「数据」「Action」页，确认浅色/深色都没有布局或
  空态异常。
- 新增共享入口时，在本节补一行清单，并在提交说明里写清迁移了哪些插件。

## 标签查询控件

任务、站点、储物三处的标签筛选/选择控件共用 `packages/addons/lib/tag-filter.cjs`。三个
插件只保留薄适配文件（`client/ui/tagfilter.cjs`，各 74–86 行），提供 action 名、分页字段映射、
类名前缀与「已选区」渲染回调；交互逻辑全部在共享层。具体接入：

- 任务：`tasks.tagOptions`、`wbt-tagfilter`/`wbt-tagmenu`，`dedupe: false`，展示每个标签的计数。
- 站点：`siteTags.search`、`wbs-tagfilter`/`wbs-tagmenu`，`stopPropagation: true`，菜单宽 260。
- 储物：`storageTags.search` + `storageTags.byIds`、`wbi-tagfilter`/`wbi-tagmenu`，文案走 `ui.tr(lang, …)`。

改共享层时必须回归三处；交互契约如下：

- 触发按钮显示「标签筛选」，有选中时追加 ` · n`；展开后搜索框自动聚焦。
- 关键词输入 200ms 防抖；关键词变化回到第 1 页，清空后立即回第 1 页。
- 每页 20 条；列表滚动到 `scrollTop + clientHeight >= scrollHeight - 24` 时请求下一页，
  追加前按 id 去重，防止触底事件重复触发造成重复项；没有下一页时底部显示「没有更多」。
- 已选标签单独成区块并置顶，每项带 × 可单个移除，另有「清空」清空全部；搜索与翻页
  都不能丢失已选（翻页后已选项仍要显示名称）。
- 文案三态：加载中… / 没有匹配的标签（有搜索词但无结果）/ 暂无标签（库里没有标签或
  标签域不可用）；标签域不可用或未启用时整个控件不渲染，不显示禁用态空壳。
- Esc 关闭菜单：输入框 `onKeyDown` 与 `document` 级监听都要有，避免焦点移出后关不掉。
- 数据源只用本插件注册的 action：任务 `tasks.tagOptions`、站点 `siteTags.search`、
  储物 `storageTags.search`；不要直连其他插件的接口。
- 颜色、边框、阴影、悬浮态全部用 `--wb-*` / `--line` / `--surface` 等主题变量。
- 窄栏（容器 < 480px）下菜单不再相对按钮浮出，而是改为左右各 8px、贴工具栏下沿的整栏
  菜单：按钮位于工具栏中间时，260px 浮层会以按钮右缘对齐而溢出容器左边界；改为整栏后
  无论工具栏是否换行都不会横向滚动。宽栏保持按钮下方 260px 浮层，并限制在容器内。

唯一允许的差异是展示字段：任务侧显示每个标签的使用数量（`total`），站点与储物不展示计数。

## 日期控件

任务、工资、标签、站点原来各写一份日历/日期输入，行为与视觉都在漂移。现在只保留一份
实现：`packages/addons/lib/date-picker.cjs`（行为）+ `date-picker-styles.cjs`（样式）。

四种形态按粒度选，不要再用原生 `<input type="date">` 顶替：

| 形态 | 用途 | 值 |
| --- | --- | --- |
| `DatePicker` | 选一个日期：发薪日、目标日期、截止日期 | `YYYY-MM-DD` |
| `RangePicker` | 选一段起止：清单筛选「发布时间范围」、统计页自定义区间 | `{ from, to }`，允许只留一端 |
| `MonthPicker` | 选一个月份：按月归档/筛选 | `YYYY-MM` |
| `InlineCalendar` | 直接铺开的月历：日历类页面、看板侧栏 | `YYYY-MM-DD` |

接入约定：

- `prefix` 传插件自己的前缀（`wbt`/`wbsal`/`wbg`/`wbs`），类名与 keyframes 都由它派生，
  同一页面不会互相覆盖；样式用 `require("../../../lib/date-picker-styles.cjs")(prefix)`
  追加到插件样式数组（`client/` 根目录的文件是 `../../lib/...`）。
- React 从 `props.React` / `props.h` 取，取不到才回退真实 `react`：插件视图本来就有
  `React`/`h`，务必透传；这样预览脚本与 node 冒烟测试能用替身 React 渲染，不需要浏览器。
- 值一律 UTC 语义的字符串：日期 `YYYY-MM-DD`、月份 `YYYY-MM`；不要把 `Date` 对象或本地
  时间戳塞进来。工具函数 `todayISO/validDate/shiftDate/shiftMonth/normalizeRange/monthLabel/
  daysInMonth` 直接复用，不要在插件里再写一份。
- 交互契约：点触发按钮开合、Esc 与点空白处关闭、方向键移动焦点、`min`/`max` 禁选、
  `clearable` 出「×」清空；`RangePicker` 先选开始再选结束，可「仅起始 / 仅截止」。
- 无障碍：触发按钮带 `aria-haspopup="dialog"` 与 `aria-expanded`，弹层 `role="dialog"`，
  日期格是 `<button>` 且选中项 `aria-pressed`，今天 `aria-current="date"`。
- 颜色只用 `--wb-*` 令牌（选中态 `var(--wb-accent)` + `var(--wb-on-accent)`），禁止写死
  `#fff`/`#000`/`rgba()`；深色、浅色都要实机看一眼。
- 共享控件的行为测试在 `scripts/test-date-picker.test.mjs`（`node --test`），改了实现必须
  同时更新测试，并回归 tasks/sites/tags/salary 的日期入口。

当前接入：工资记录页发薪日期、任务创建/编辑弹窗四个日期、任务筛选「发布时间范围」、
任务/标签/站点统计页自定义范围；预览脚本 `scripts/preview-pickers.mjs` 可生成深浅两屏
截图（`/tmp/pickers-preview.html`）。

## 统计图表基件

站点、标签、任务三个统计页此前各写一份自绘图表，主体代码逐字相同。现在只保留
`packages/addons/lib/stats-charts.cjs`（420 行），三处改为注入差异的薄包装：

| 插件 | 包装 | 注入内容 |
| --- | --- | --- |
| 站点 | `sites/client/stats/charts.cjs`（23 行） | 9 个 lucide 图标表 |

| 任务 | `tasks/client/stats/charts.cjs`（422 行） | 自有 Section/Trend 提示/可点 Histogram/数据表样式，基件复用 lib |

接入约定：

- 视图取色必须用 `makeCharts(prefix)` 返回值里的 `colors`（包装层要把它透传出去），

- 数据项有 `note` 字段、且要在图例/饼图提示里展示时传 `showNote: true`（目前只有标签页）。
- 改基件后必须按上面的渲染清单做 SSR 对比（见「验证」），确认三处标记完全一致。

## 图标

13 个插件的图标统一走 `packages/addons/lib/icons.cjs`：`create(prefix, 图标表, options)`
生成 `{ ICONS, Icon, tabIcon? }`，插件侧只在自己的 `client/ui/icons.cjs` 里声明别名与选项，
视图里用 `ICONS["图标名"]` 或 `h(Icon, { name })`，不再内联 `require("lucide-react/icons/…")`。
`scripts/test-shared-ui.mjs` 会扫描并拦住回退。

图标模块从 29 个涨到 75 个、`client.js` 从 252KB 涨到 296KB，直接触发现有体积预算断言
（`scripts/test-storage-visual.mjs`）。

## 对话框、按钮与骨架屏

- 对话框外壳统一用 `lib/overlay.cjs`：点遮罩关闭、Esc 关闭（先 `preventDefault` 再回调，
  避免 React 立刻替换 document 监听导致重复触发）、Tab 在对话框内循环、关闭后焦点归位。
  标签名（`section`/`div`）、遮罩与对话框类名、标题栏渲染、`aria-label` 来源都用 options 注入。
  `header` 传了才渲染标题栏；标题栏里的关闭按钮由插件用自己的按钮组件渲染。
- 每个对话框都要有可读的无障碍名称：`ariaLabelOf` 返回 `props.title`，或调用方直接传
  `"aria-label"`（站点四处对话框即如此）。
- 按钮统一用 `lib/button.cjs`：`createButton({ prefix, Icon })`。图标按钮自动补
  `aria-label`（取 `props["aria-label"]` 或 `children`）与 `title`，类名追加
  `${prefix}-icon-only` / `${prefix}-icon-text`。
- 骨架屏统一用 `lib/skeleton.cjs`：`createSkeleton({ prefix, text })`，`text(lang)` 负责
  中英文案。
- 业务弹窗内部结构（字段、步骤、校验）留在插件内：`overlay` 只负责外壳，不要把它写成
  带业务分支的万能弹窗。
- 外壳选项（2026-11 全量接入时补齐）：`ariaLabelledByOf`（用标题元素 id 作名称，优先于
  `aria-label`）、`closeOnEscape(props)`、`closeOnMask(props)`、`onKeyDown(e, props, ref)`

## 跨插件界面插槽

插件想在**别的插件界面**里加一个按钮/一段设置，不再靠"装一个依赖 + 改对方代码"，而是往宿主
声明的插槽里贡献组件。设计见 [`../跨插件界面插槽设计.md`](../跨插件界面插槽设计.md)。

宿主目前只开四个槽，**不在这四个里的 id 会被注册表拒绝**：

| 插槽 | 落点位置 | 组件收到的 props |
| --- | --- | --- |
| `item.actions` | 单条对象的操作条（邮件详情 / 任务详情） | `item`：`{kind, id, title, subtitle?, description?}`，`kind` 是 `mail.message` 或 `task` |
| `view.toolbar` | 插件视图工具条 | `view`：`{addonId, viewId}` |
| `settings.sections` | 配置页分段 | `owner`：落点插件 id |
| `home.card.footer` | 首页插件卡片底部 | `card`：`{addonId, title}` |

规则：

1. **贡献必须写进 `registerAddon({ slots: [...] })`**。宿主按 `addonId` 撤销；用
   `host.registerSlot()` 单独注册的贡献在插件卸载后无法回收，只用于动态场景。
2. **属主只提供引用，不提供内部对象**。落点传的是 `item` 这类轻量引用，贡献方要做重活就调
   **自己域的 action**（走它自己的审计），不要直接读对方的表或 api。
3. **属主不得内建来源解析**。落点把原文（如任务 `description`）整段透传给贡献方，
   贡献方自己认自己写的标记（`wb-mail:<id>`）并自己跳转；属主里出现 `MAIL_REF`、`SITE_REF`
   这类分支就说明插槽用错了——那等于每加一个来源都要改一次属主。
4. **没有贡献时落点渲染 `null`**，属主不要自己判断"有没有人挂"、不要预设占位块。
5. **贡献组件要轻**。渲染期不发同步重活；需要数据的用 `api.call(...)` 异步取并自己处理
   loading/失败。一个贡献抛错会被错误边界单独吞掉，但别指望它兜性能问题。
6. **样式自兜底**：贡献渲染在别人的页面里，拿不到属主的 CSS 变量（如任务的 `--wbt-*`）。
   颜色仍只能用主题 token，写 `var(--wbt-line, var(--wb-border))` 这种带兜底的形式。
7. **order 只表达视觉优先级，不表达依赖**。跨插件依赖一律走 action，不要用 order 排序去
   "等"另一个贡献先渲染。

验证：改完跑 `pnpm test:slots`（`scripts/test-addon-slots.mjs` 覆盖排序/隔离/撤销/双向贡献与"属主零来源代码"，`scripts/audit-slots.mjs`
加载已构建产物，检查插槽 id 是否在白名单、跨插件 id 是否重复）。**插槽 id 打错不会报错，只会
永远不显示**——所以这步不能省。

## 验证

不能只看普通浏览器：浏览器里 `--dsh-frame-top-clearance` 与
`--dsh-frame-leading-clearance` 默认为 `0`，会掩盖桌面端问题。

  （clearance 32px）截图；
- 在独立 profile 实机确认浅色、深色都只有一层顶栏；
- 确认任务树顶部控件可点击，不被顶栏或拖拽区吞掉；
- 确认页面没有横向溢出，760px 以下单列布局正常。

深色验证使用 DSH 主题开关：`html[data-ds-theme-source]` 与
`body[data-ds-dark-theme]` 同时切换，不能只改页面局部 class。

## 常见错误

- 给视图容器加 `max-width:1180px; margin:0 auto`，宽屏两侧出现大留白；
- 顶栏用 `padding-top` 预留给系统标题栏，形成一条与页面同色的空白带；
- 给整条顶栏或标题区加 `-webkit-app-region: drag`，按钮点不动；
- 写死 `#fff` 背景，切到深色主题后仍是白底；
- 只截浅色或只截浏览器，不模拟桌面端 clearance；
- 新增第二行视图标签，和顶栏叠成两层。
