# 储物卡片设计（反馈 01a1be95）

名称保留「储物 / Storage」。卡片顺序为标题与库存 → 标签 → 品牌/单位及创建更新时间 → 描述 → 图片 → 底部操作。空标签、元信息、描述、图片均不输出占位块；库存 0 正常显示。

描述共用 packages/addons/lib/description.cjs 的 wb-desc 样式：左边框 2px、蓝色 7% 淡底、12.5px/1.6，正文继承主题前景色，不沿用 metadata muted 色。tasks 原位追加 wb-desc class，不改变原有编辑行为或主体行数。储物描述默认三行，通过真实 scrollHeight/clientHeight 及 ResizeObserver 决定是否出现展开按钮；展开后保留收起。

卡片 padding 14px、radius 10px，操作行 margin-top:auto，编辑/删除为 sm ghost，至少 32×32；危险色只在删除 hover 出现。标签同样保留 32px 点击高度。hover 微浮并提亮边框，focus-visible 保留轮廓，减少动态效果偏好下不浮动。图片 80×60（4:3），默认一张和 +N；+N 展开其余安全 URL 缩略图，每张仍可预览。

## 网格的取舍

260px × 5 + 14px × 4 = 1356px，无法同时满足 1280px 内容宽五列和 260px 硬下限。因此默认使用 repeat(auto-fill,minmax(min(260px,100%),1fr))，以实际内容容器达到 1280px 为断点切换五列，每卡 244.8px；五列及以上宽度保持五列。768px 内容宽为两列，360px 内容宽为一列，内容小于 260px 也不溢出。容器查询而非 viewport 查询避免侧栏挤压内容时仍强制五列。1280px 的整个浏览器视口若另有侧栏，不等于 1280px 内容区，可能合理降为四列或更少。

## 验证边界

node scripts/test-storage-cards.mjs 直接加载源组件，用状态及 effect 渲染夹具检查空块、层级、零库存、超长名称、图片安全过滤/+N 展开/预览、编辑删除及标签回调、busy 禁用、描述测量与展开收起。它不复制 CSS 快照，也不构建客户端。

最终构建后在隔离临时 profile 真实验证：1280px 内容宽五列（每卡 244.797px）；768px/360px 同源 iframe 视口分别两列/一列，document.scrollWidth 分别为 768/360，无横向溢出。空备注、无图、无标签无占位，超长名不溢出；描述展开高度 60→1000px，图库 1→2，按钮至少 32px，Tab 聚焦有 2px 轮廓。实际暗色主题描述前景 rgb(249,250,251)、背景 rgb(39,41,48)，对比度 13.896:1。截图载体存在一帧滞后，仅采用逐张视觉核实的截图；窄屏尺寸以 DOM 测量为证，不能用缓存截图代替。
